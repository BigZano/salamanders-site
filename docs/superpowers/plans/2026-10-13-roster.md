# Roster (ORBAT) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the internal Roster page's data pipeline (a live, Legion-gated `GET /roster` and a command-only `GET /roster/infirmary`), plus a structural client page and a synthetic fixture for the frontend design pass on the Windows machine.

**Architecture:** A pure core (`rosterCore.js`) turns raw Discord guild-member objects into the order of battle using a curated ladder (`rosterLadder.js`). `roster.js` pages the guild's members on a TTL and keeps the last good result in server memory only. `rosterHandler.js` gates the two endpoints with live role checks. The client is an API module, a Pinia store and a plain, structural `Roster.vue` that the Windows pass restyles.

**Tech Stack:** Bun server (`server/`), Vue 3 + Pinia + vue-router, Vitest + fast-check + Stryker, Playwright e2e against `e2e/discord-mock`.

**Spec:** `docs/superpowers/specs/2026-10-13-roster-design.md` (approved; committed `81f500c` on `feat/roster`). Read it first: the placement rules there are the source of truth for Tasks 3–5.

## Global Constraints

- This repo is public. Real member names, IDs and the legionless/Infirmary review files never go in it. The only fixture is **synthetic** (`src/data/roster.fixture.json`).
- Role ids are the live guild's as of 2026-10-13, exactly as in the spec's table. The XVIIIth Legion role is `1377787723976409211`; the Infirmary role is `1362059023481831517`.
- Roster data lives in server memory only: nothing written to the database, the repo or logs.
- `GET /roster`: 401 without or with an invalid token, 403 without the Legion role (including not in the guild), 503 when Discord is unreachable or no roster is loaded. Fails closed. `Cache-Control: no-store`. Role checks are live.
- `GET /roster/infirmary`: the above plus a command-tier role (any High Command role, Captain, Master of the Forge, Chief Librarian, Chief Apothecary, Reclusiarch Chaplain, Legion Hierarchy, or any Company Command role including the 5th and 6th "alt" roles); 403 otherwise.
- Refresh every `ROSTER_TTL_MS` (default 300000 ms = 5 min); a failed or partial refresh keeps the last good roster and retries after 60 s; `stale: true` once older than 2 × TTL; at most 20 pages of 1000 members.
- Roles decide placement and company; the single exception is servitor detection (display name containing the word "servitor" or "servo skull", case-insensitive, "servo-skull" too), which yields to any placing role.
- Precedence before placement: Voice of Vulkan account hidden everywhere → bot or Servo-Skulls role → servitors → Infirmary role → Infirmary list (Legion role not required) → no Legion role → not on the main roster → servitor-by-name (only with no placing role).
- `tier` numbers a rank within its own list (1 first); ranks sharing a tier are peers; `lateral: true` marks Terminator.
- Per the project's adversarial-testing standard: 100% coverage and 100% mutation on `rosterMember.js`, `rosterCore.js`, `roster.js`, `rosterHandler.js`. Assert behavior (return values, responses), never logs or mock calls on private state.
- Tooling on this host: run `export PATH="$PWD/node_modules/.bin:$PATH"` in the repo root first (repo-local bun; see `.husky/pre-push`). Commits go on branch `feat/roster`; the pre-commit hook runs the whole vitest suite (~15 s). End every commit message with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

Failure modes the spec implies that no single feature task would naturally test. Each has its test in the named task.

1. A member object that is malformed (no `user`, non-snowflake id, `roles` missing or not an array, duplicate ids, 10,000 roles, `null` names): must be skipped or tolerated, never throw and take the roster down. (Tasks 2 and 4.)
2. Discord answering mid-refresh with a failed page, a non-array body, or more than 20 pages: the roster must keep the last good copy and never publish a partial one, and a leaver must still disappear on the next good refresh. (Task 6.)
3. A member holding several mutually exclusive placing roles at once (High Command + Captain + Techmarine + Infirmary + Servo-Skulls): placement must be deterministic and follow the precedence in Global Constraints. (Tasks 3 and 4.)
4. Display names built to confuse the servitor pattern or the company tag (emoji, right-to-left marks, "Servitorial", "Observo-Skulls", "11th", "3rdly"): only the whole word counts, and a nickname alone must never pull a ranked member off the roster. (Tasks 2 and 3.)
5. Unauthenticated, forged or unauthorised requests: must be refused without touching the roster cache (so nobody can trigger a Discord refresh) and without leaking any field. (Task 7.)

```js
import { readFileSync } from 'node:fs'

const SPEC = readFileSync(new URL('../../docs/superpowers/specs/2026-10-13-roster-design.md', import.meta.url), 'utf8')

// Every role id the roster reads, with what it means.
function meanings() {
  const out = []
  const add = (id, what) => out.push([id, what])
  for (const r of L.HIGH_COMMAND) add(r.id, `high-command:${r.key}`)
  add(L.CAPTAIN.id, 'captain')
  add(L.VENERABLE_DREADNOUGHT.id, 'venerable-dreadnought')
  for (const r of L.DREADNOUGHTS) add(r.id, `dreadnought:${r.key}`)
  for (const s of L.SPECIALTIES) {
    add(s.head.id, `head:${s.key}`)
    for (const r of s.ranks) {
      add(r.id, `${s.key}:${r.key}`)
      for (const v of r.variants ?? []) add(v.id, `variant:${r.key}`)
    }
  }
  for (const r of L.COMPANY_RANKS) {
    add(r.id, `rank:${r.key}`)
    for (const v of r.variants ?? []) add(v.id, `variant:${r.key}`)
  }
  for (const c of L.COMPANIES) {
    add(c.roleId, `company:${c.number}`)
    c.commandRoleIds.forEach((id, i) => add(id, `command:${c.number}:${i}`))
  }
  add(L.LEGION_ROLE, 'legion')
  add(L.INFIRMARY_ROLE, 'infirmary')
  add(L.VOICE_OF_VULKAN_ROLE, 'voice-of-vulkan')
  add(L.SERVO_SKULLS_ROLE, 'servo-skulls')
  add(L.LEGION_HIERARCHY_ROLE, 'legion-hierarchy')
  return out
}

    for (const [id, what] of meanings()) expect(id, what).toMatch(SNOWFLAKE)

  it('never serve two meanings', () => {
    const seen = new Map()
```

```js
/**
 * Pure helpers that turn one raw Discord guild-member object into what the
 * roster reads from it. Nothing here touches the network or a clock.
 */
import { nameOf } from './displayNames.js'

export const UNNAMED = 'Unnamed Member'

const SNOWFLAKE = /^\d{17,20}$/
const AVATAR_HASH = /^(?:a_)?[0-9a-f]{32}$/
const CDN = 'https://cdn.discordapp.com'
// Whole words only: "Servitorial" and "Observo-Skulls" must not match.
const SERVITOR_NAME = /(?<![\p{L}\p{N}])(?:servitors?|servo[\s-]?skulls?)(?![\p{L}\p{N}])/iu
// "3rd", "7th": an ordinal 1-7 standing alone, so "11th" and "3rdly" do not count.
const COMPANY_TAG = /(?<![\p{L}\p{N}])([1-7])(?:st|nd|rd|th)(?![\p{L}\p{N}])/giu

const isHash = (v) => typeof v === 'string' && AVATAR_HASH.test(v)

/** The member's server avatar, else their account avatar, as a CDN url; null if neither is well formed. */
export function avatarUrl(member, guildId) {
  const uid = member?.user?.id
  if (typeof uid !== 'string' || !SNOWFLAKE.test(uid)) return null
  if (isHash(member.avatar) && typeof guildId === 'string' && SNOWFLAKE.test(guildId)) {
    return `${CDN}/guilds/${guildId}/users/${uid}/avatars/${member.avatar}.png?size=64`
  }
  if (isHash(member.user.avatar)) return `${CDN}/avatars/${uid}/${member.user.avatar}.png?size=64`
  return null
}

/** Company numbers a display name claims ("… 3rd Co."), distinct and ascending. */
export function companiesInName(name) {
  const found = new Set()
  for (const m of String(name).matchAll(COMPANY_TAG)) found.add(Number(m[1]))
  return [...found].sort((a, b) => a - b)
}

export const isServitorName = (name) => SERVITOR_NAME.test(name)

/** → { id, name, avatar, bot, roles: Set } for a well-formed member object, else null. */
export function memberFacts(raw, guildId) {
  const id = raw?.user?.id
  if (typeof id !== 'string' || !SNOWFLAKE.test(id)) return null
  return {
    id,
    name: nameOf(raw) ?? UNNAMED,
    avatar: avatarUrl(raw, guildId),
    bot: raw.user.bot === true,
    roles: new Set(Array.isArray(raw.roles) ? raw.roles.filter((r) => typeof r === 'string') : []),
  }
}
```

```js
/**
 * The roster as data. Pure: raw Discord guild-member objects in, the order of
 * battle out; no I/O, no clock. Placement is by role; the one place a name
 * decides is servitor detection (routeOf). Rules and ladder:
 * docs/superpowers/specs/2026-10-13-roster-design.md and rosterLadder.js.
 */
import {
  COMMAND_TIER_ROLES,
  INFIRMARY_ROLE,
  LEGION_ROLE,
  PLACING_ROLES,
  SERVO_SKULLS_ROLE,
  VOICE_OF_VULKAN_ROLE,
} from './rosterLadder.js'
import { isServitorName } from './rosterMember.js'

/** May this caller (their held role ids) open the Infirmary area? */
export const commandTier = (roleIds) => roleIds.some((id) => COMMAND_TIER_ROLES.has(id))

/**
 * Where a member goes before any placement: 'hidden' (listed nowhere),
 * 'servitor', 'infirmary' or 'roster'. First match wins, in this order.
 */
export function routeOf(f) {
  if (f.roles.has(VOICE_OF_VULKAN_ROLE)) return 'hidden'
  if (f.bot || f.roles.has(SERVO_SKULLS_ROLE)) return 'servitor'
  if (f.roles.has(INFIRMARY_ROLE)) return 'infirmary'
  if (!f.roles.has(LEGION_ROLE)) return 'hidden'
  // The name is the weakest signal: it counts only when no placing role does.
  if (isServitorName(f.name) && ![...PLACING_ROLES].some((id) => f.roles.has(id))) return 'servitor'
  return 'roster'
}
```

```js
  ...r.branches.flatMap((b) => [...b.head.members.filter((m) => !m.acting), ...b.aside, ...b.rows.flatMap((x) => x.members)]),
  ...r.unassigned.rows.flatMap((x) => x.members),
]

describe('buildRoster: shape', () => {
  it('returns all twelve branches, vacant, for an empty or hostile input', () => {
    for (const input of [[], null, undefined, 'x', {}, [null, 5, 'x', {}, { user: null }]]) {
      const r = buildRoster(input, { guildId: GUILD })
      expect(r.highCommand).toEqual([])
      expect(r.unassigned).toEqual({ rows: [] })
      expect(r.servitors).toEqual([])
      expect(r.branches.map((b) => b.key)).toEqual(L.BRANCHES.map((b) => b.key))
      for (const b of r.branches) expect(b).toMatchObject({ aside: [], rows: [], head: { members: [], vacant: true } })
    }
  })

  it('describes each branch and its head rank', () => {
    const r = build()
    expect(branch(r, 'company-3')).toEqual({
      key: 'company-3', kind: 'company', label: '3rd Battle Company', number: 3,
      head: { rank: { key: 'captain', label: 'Captain', tier: 1 }, members: [], vacant: true }, aside: [], rows: [],
    })
    expect(branch(r, 'venerable-dreadnoughts')).toMatchObject({ kind: 'dreadnoughts', label: 'Venerable Dreadnoughts', head: { rank: { key: 'venerable-dreadnought' } } })
    expect(branch(r, 'venerable-dreadnoughts')).not.toHaveProperty('number')
    expect(branch(r, 'forge')).toMatchObject({ kind: 'specialty', label: 'Forge', head: { rank: { key: 'master-of-the-forge' } } })
  })

  it('gives a member their avatar, name and company from roles', () => {
    const raw = mem([LEG, cr('scout'), co(4)], { name: 'Brother Four' })
    raw.avatar = 'c'.repeat(32)
    const m = rowOf(branch(build(raw), 'company-4'), 'scout')[0]
    expect(m).toEqual({
      id: raw.user.id, name: 'Brother Four', company: 4,
      avatar: `https://cdn.discordapp.com/guilds/${GUILD}/users/${raw.user.id}/avatars/${'c'.repeat(32)}.png?size=64`,
    })
  })
})
```

```js
const cmp = (a, b) => (a < b ? -1 : a > b ? 1 : 0)
/** Name, case-insensitive, then id: a total order, so output never depends on input order. */
const byName = (a, b) => cmp(a.name.toLowerCase(), b.name.toLowerCase()) || cmp(a.id, b.id)

/** A member's highest rank within `ranks`, counting a variant role as its owner's rank. */
const heldRank = (roles, ranks) => ranks.find((r) => roles.has(r.id) || r.variants?.some((v) => roles.has(v.id)))
const rankView = ({ key, label, tier, lateral }) => ({ key, label, tier, ...(lateral ? { lateral: true } : {}) })

const VARIANT_OWNERS = [...COMPANY_RANKS, ...SPECIALTIES.flatMap((s) => s.ranks)]

/** Company from roles only: the lowest-numbered company role, else the company a variant role implies. */
function companyOf(roles) {
  const held = COMPANIES.filter((c) => roles.has(c.roleId)).map((c) => c.number)
  if (held.length > 0) return { company: held[0], also: held.slice(1) }
  for (const owner of VARIANT_OWNERS) {
    const v = owner.variants?.find((x) => roles.has(x.id))
    if (v) return { company: v.company, also: [] }
  }
  return { company: null, also: [] }
}

/** The public view of one member. */
function member(f, { acting = false } = {}) {
  const { company, also } = companyOf(f.roles)
  const claimed = new Set(company === null ? [] : [company, ...also])
  return {
    id: f.id,
    name: f.name,
    avatar: f.avatar,
    company,
    ...(also.length > 0 ? { alsoCompanies: also } : {}),
    ...(acting ? { acting: true } : {}),
    ...(companiesInName(f.name).some((n) => !claimed.has(n)) ? { nameMismatch: true } : {}),
  }
}

/** Rules 2-10 of the spec, first match wins. */
function place(f, company) {
  const { roles } = f
  const hc = heldRank(roles, HIGH_COMMAND)
  if (hc) return { to: 'highCommand', rank: hc }
  const early = SPECIALTIES.find((s) => s.headFirst && roles.has(s.head.id))
  if (early) return { to: early.key, head: true }
  const home = company === null ? null : `company-${company}`
  // A Captain who is also a Venerable Dreadnought is shown with their company.
  if (home && roles.has(CAPTAIN.id)) return { to: home, head: true }
  if (roles.has(VENERABLE_DREADNOUGHT.id)) return { to: 'venerable-dreadnoughts', head: true }
  if (home && heldRank(roles, DREADNOUGHTS)) return { to: home, aside: true }
  const late = SPECIALTIES.find((s) => !s.headFirst && roles.has(s.head.id))
  if (late) return { to: late.key, head: true }
  for (const s of SPECIALTIES) {
    const rank = heldRank(roles, s.ranks)
    if (rank) return { to: s.key, rank }
  }
  return { to: home ?? 'unassigned', rank: heldRank(roles, COMPANY_RANKS) ?? null }
}

/** Well-formed, de-duplicated members (the first of a duplicate id wins). */
function people(rawMembers, guildId) {
  const seen = new Set()
  const out = []
  for (const raw of Array.isArray(rawMembers) ? rawMembers : []) {
    const f = memberFacts(raw, guildId)
    if (!f || seen.has(f.id)) continue
    seen.add(f.id)
    out.push(f)
  }
  return out
}

const rowsOf = (byKey, ranks) =>
  ranks.filter((r) => byKey.get(r.key).length > 0).map((r) => ({ rank: rankView(r), members: byKey.get(r.key).sort(byName) }))

/**
 * The order of battle: { highCommand, branches, unassigned, servitors }.
 * `rawMembers` are Discord guild-member objects; `guildId` builds avatar urls.
 */
export function buildRoster(rawMembers, { guildId } = {}) {
  const highCommand = new Map(HIGH_COMMAND.map((r) => [r.key, []]))
  const unassigned = new Map([...COMPANY_RANKS, NO_RANK].map((r) => [r.key, []]))
  const slots = new Map(BRANCHES.map((b) => [b.key, { head: [], aside: [], rows: new Map(b.ranks.map((r) => [r.key, []])) }]))
  const servitors = []
  const eligible = [] // roster members who may stand in as an acting head

  for (const f of people(rawMembers, guildId)) {
    const to = routeOf(f)
    if (to === 'servitor') {
      servitors.push({ id: f.id, name: f.name, avatar: f.avatar, company: null, ...(f.bot ? { bot: true } : {}) })
    }
    if (to !== 'roster') continue

    const placed = place(f, companyOf(f.roles).company)
    const m = member(f)
    if (placed.to === 'highCommand') highCommand.get(placed.rank.key).push(m)
    else if (placed.to === 'unassigned') unassigned.get((placed.rank ?? NO_RANK).key).push(m)
    else {
      const slot = slots.get(placed.to)
      if (placed.head) slot.head.push(m)
      else if (placed.aside) slot.aside.push(m)
      else slot.rows.get((placed.rank ?? NO_RANK).key).push(m)
    }
    if (placed.to === 'highCommand' || f.roles.has(CAPTAIN.id)) eligible.push(f)
  }

  // A company with no Captain is headed, as acting, by High Command and other
  // Captains holding its Company Command role.
  for (const b of BRANCHES) {
    const slot = slots.get(b.key)
    if (b.kind !== 'company' || slot.head.length > 0) continue
    slot.head = eligible.filter((f) => b.commandRoleIds.some((id) => f.roles.has(id))).map((f) => member(f, { acting: true }))
  }

  return {
    highCommand: rowsOf(highCommand, HIGH_COMMAND),
    branches: BRANCHES.map((b) => {
      const slot = slots.get(b.key)
      return {
        key: b.key,
        kind: b.kind,
        label: b.label,
        ...(b.kind === 'company' ? { number: b.number } : {}),
        head: { rank: rankView(b.head), members: slot.head.sort(byName), vacant: slot.head.length === 0 },
        aside: slot.aside.sort(byName),
        rows: rowsOf(slot.rows, b.ranks),
      }
    }),
    unassigned: { rows: rowsOf(unassigned, [...COMPANY_RANKS, NO_RANK]) },
    servitors: servitors.sort(byName),
  }
}
```

```js
/**
 * The roster feed: pages the guild's member list on a TTL, builds the order of
 * battle and the Infirmary list from it, and keeps the last good copy in this
 * process's memory only (never the database, the repo or logs). Own cache and
 * timer, separate from displayNames.js and the discord-members.json bake.
 *
 * Once stale, the old copy keeps answering while a refresh runs; a failed or
 * partial refresh (any page failing, a non-array body, more than maxPages)
 * keeps the last good copy and retries after retryMs. Members who left drop
 * out on the next good refresh. Listing members needs the bot's GUILD_MEMBERS
 * intent, same as displayNames.js and scripts/fetch-discord-members.mjs.
 */
import { buildInfirmary, buildRoster } from './rosterCore.js'

const PAGE = 1000
const SNOWFLAKE = /^\d{17,20}$/

export function createRoster({
  fetchImpl = fetch,
  apiBase,
  guildId,
  botToken,
  now = Date.now,
  ttlMs = 5 * 60_000,
  retryMs = 60_000,
  timeoutMs = 10_000,
  maxPages = 20,
}) {
  for (const [key, v] of Object.entries({ ttlMs, retryMs, timeoutMs, maxPages })) {
    if (!Number.isFinite(v) || v <= 0) throw new RangeError(`${key} must be a positive number`)
  }
  const configured = [apiBase, guildId, botToken].every((v) => typeof v === 'string' && v !== '')

  let view = null // { roster, infirmary, at }
  let nextRefreshAt = -Infinity
  let inflight = null

  /** → every guild member, or null if any page fails (the caller keeps the old copy). */
  async function load() {
    const all = []
    let after = '0'
    for (let i = 0; i < maxPages; i++) {
      const res = await fetchImpl(`${apiBase}/v10/guilds/${guildId}/members?limit=${PAGE}&after=${after}`, {
        headers: { Authorization: `Bot ${botToken}` },
        signal: AbortSignal.timeout(timeoutMs),
      })
      if (res.status !== 200) return null
      const members = await res.json()
      if (!Array.isArray(members)) return null
      all.push(...members)
      if (members.length < PAGE) return all
      after = members[PAGE - 1]?.user?.id
      if (!SNOWFLAKE.test(after)) return null
    }
    return null // more than maxPages: refuse a partial roster
  }

  function settle(members) {
    if (members) {
      view = {
        roster: buildRoster(members, { guildId }),
        infirmary: buildInfirmary(members, { guildId }),
        at: now(),
      }
    }
    nextRefreshAt = now() + (members ? ttlMs : retryMs)
  }

  function refresh() {
    inflight ??= load()
      .then(settle)
      .catch(() => settle(null))
      .finally(() => {
        inflight = null
      })
    return inflight
  }

  /** → { roster, infirmary, fetchedAt, stale } or null if no roster has ever loaded. Waits only for the first load. */
  async function current() {
    if (!configured) return null
    if (now() >= nextRefreshAt) {
      const pending = refresh()
      if (!view) await pending
    }
    if (!view) return null
    return {
      roster: view.roster,
      infirmary: view.infirmary,
      fetchedAt: new Date(view.at).toISOString(),
      stale: now() - view.at > 2 * ttlMs,
    }
  }

  return { current }
}
```

```js
/**
 * GET /roster and GET /roster/infirmary. The caller's identity and roles are
 * checked live against Discord on every request (discordRoles.js), and every
 * uncertain path fails closed. A caller who is refused never reaches the
 * roster cache, so nobody can trigger a Discord refresh without being a
 * Legion member. Responses are never cached.
 */
import { Upstream } from './discordRoles.js'
import { commandTier } from './rosterCore.js'
import { LEGION_ROLE } from './rosterLadder.js'

const reply = (status, body) =>
  new Response(JSON.stringify(body), {
    status,
    headers: { 'Content-Type': 'application/json', 'Cache-Control': 'no-store' },
  })

export function createRosterHandler({ roles, roster }) {
  return async function handle(request, url) {
    const { pathname } = url
    if (request.method !== 'GET' || (pathname !== '/roster' && pathname !== '/roster/infirmary')) return null
    try {
      const user = await roles.identify(request)
      if (!user) return reply(401, { error: 'Sign in with Discord.' })
      const held = await roles.rolesOf(user.id)
      if (!held || !held.includes(LEGION_ROLE)) return reply(403, { error: 'The roster is open to the XVIIIth Legion.' })
      const command = commandTier(held)
      if (pathname === '/roster/infirmary' && !command) {
        return reply(403, { error: 'The Infirmary list is open to company command and above.' })
      }
      const snap = await roster.current()
      if (!snap) return reply(503, { error: 'The roster is not available yet. Try again.' })
      if (pathname === '/roster') {
        return reply(200, { fetchedAt: snap.fetchedAt, stale: snap.stale, viewer: { infirmary: command }, ...snap.roster })
      }
      return reply(200, { fetchedAt: snap.fetchedAt, stale: snap.stale, count: snap.infirmary.length, members: snap.infirmary })
    } catch (err) {
      if (err instanceof Upstream) return reply(503, { error: 'Discord could not be reached. Try again.' })
      throw err
    }
  }
}
```

```js
/**
 * Named states of the roster page for design work, derived from the full
 * synthetic fixture (scripts/roster-fixture.mjs). Dev only; see rosterFixture.js.
 *   full     every case at once
 *   stale    the server's "out of date" flag set
 *   empty    nobody on the roster: every head vacant
 *   loading  the page before anything has arrived (never resolves)
 *   signin   signed out
 *   denied   signed in, but not in the Legion
 *   error    the server could not be reached, and nothing is cached
 */
export const SCENES = ['full', 'stale', 'empty', 'loading', 'signin', 'denied', 'error']

const STATES = {
  loading: {},
  signin: {},
  denied: { message: 'The roster is open to the XVIIIth Legion.' },
  error: { message: 'Could not reach the roster server.' },
}

const emptied = (roster) => ({
  ...roster,
  highCommand: [],
  branches: roster.branches.map((b) => ({ ...b, head: { ...b.head, members: [], vacant: true }, aside: [], rows: [] })),
  unassigned: { rows: [] },
  servitors: [],
})

/** The fixture as the named scene, in the shape the roster store reads. An unknown name gives 'full'. */
export function sceneOf(fixture, name) {
  const scene = SCENES.includes(name) ? name : 'full'
  if (scene in STATES) return { _fixture: true, scene, status: scene, ...STATES[scene] }
  const { roster, infirmary } = fixture
  if (scene === 'stale') {
    return { _fixture: true, scene, roster: { ...roster, stale: true }, infirmary: { ...infirmary, stale: true } }
  }
  if (scene === 'empty') {
    return { _fixture: true, scene, roster: emptied(roster), infirmary: { ...infirmary, count: 0, members: [] } }
  }
  return { _fixture: true, scene, roster, infirmary }
}
```

```js
import { defineStore } from 'pinia'
import { markRaw } from 'vue'
import * as api from '../lib/rosterApi'
import { loadFixture } from '../lib/rosterFixture'

// One counter per kind of load: a response only lands if no later call (or
// reset) has started since, so a slow answer can never overwrite a newer one.
let rosterSeq = 0
let infirmarySeq = 0

const statusOf = (err) => (err?.status === 401 ? 'signin' : err?.status === 403 ? 'denied' : 'error')
const messageOf = (err) => err?.message || 'Could not reach the roster server.'

export const useRoster = defineStore('roster', {
  // Server responses are wholesale-replaced snapshots, never edited in place.
  state: () => ({ status: 'idle', roster: null, infirmaryStatus: 'idle', infirmary: null, message: '' }),
  actions: {
    async load(token) {
      const mine = ++rosterSeq
      const fixture = await loadFixture()
      if (mine !== rosterSeq) return
      if (fixture?.status) {
        // A dev "state" scene (loading, signin, denied, error): show that state, with no roster.
        this.$patch({ status: fixture.status, message: fixture.message ?? '', roster: null, infirmary: null, infirmaryStatus: 'idle' })
        return
      }
      if (!fixture && !token) {
        this.status = 'signin'
        return
      }
      if (!this.roster) this.status = 'loading'
      try {
        const data = fixture ? fixture.roster : await api.getRoster(token)
        if (mine !== rosterSeq) return
        this.roster = markRaw(data)
        this.status = 'ready'
        this.message = ''
      } catch (err) {
        if (mine !== rosterSeq) return
        this.status = statusOf(err)
        this.message = messageOf(err)
        // A refused caller keeps nothing; a server hiccup keeps the last copy on screen.
        if (this.status !== 'error') {
          this.roster = null
          this.infirmary = null
          this.infirmaryStatus = 'idle'
        }
      }
    },

    async loadInfirmary(token) {
      const mine = ++infirmarySeq
      const fixture = await loadFixture()
      if (mine !== infirmarySeq) return
      if (fixture?.status) return // a state scene has no Infirmary list
      try {
        const data = fixture ? fixture.infirmary : await api.getInfirmary(token)
        if (mine !== infirmarySeq) return
        this.infirmary = markRaw(data)
        this.infirmaryStatus = 'ready'
      } catch (err) {
        if (mine !== infirmarySeq) return
        this.infirmaryStatus = statusOf(err)
        if (this.infirmaryStatus === 'denied') this.infirmary = null
      }
    },

    reset() {
      rosterSeq++
      infirmarySeq++
      this.$patch({ status: 'idle', roster: null, infirmaryStatus: 'idle', infirmary: null, message: '' })
    },
  },
})
```

```js
/**
 * Builds src/data/roster.fixture.json: a SYNTHETIC roster (invented names, the
 * real role structure) for designing the page without the live server. It runs
 * the real buildRoster/buildInfirmary over made-up guild members, so the
 * fixture can never drift from the API contract. Real member data never goes
 * here (the repo is public).
 *
 *   node scripts/roster-fixture.mjs
 */
import { writeFile } from 'node:fs/promises'
import { pathToFileURL } from 'node:url'
import { buildInfirmary, buildRoster } from '../server/src/rosterCore.js'
import * as L from '../server/src/rosterLadder.js'

const GUILD = '1322056087792521269'
const OUT = new URL('../src/data/roster.fixture.json', import.meta.url)
const FETCHED_AT = '2026-01-01T12:00:00.000Z'

const LAST = ['Ashgrave', 'Brandt', 'Cinder', 'Dross', 'Emberly', 'Flint', 'Garrow', 'Holt', 'Ironside', 'Jorrik', 'Kestrel', 'Lowe', 'Marrow', 'Nightshade', 'Oakheart']

const cmd = (n) => L.COMPANIES[n - 1].commandRoleIds[0]
const cr = (key) => L.COMPANY_RANKS.find((r) => r.key === key)
const spec = (key) => L.SPECIALTIES.find((s) => s.key === key)

export function syntheticGuild() {
  let n = 0
  const members = []
  /** One made-up member. Ids are 18-digit and start with 9: synthetic and unmistakable in the fixture. A real account could in theory share the range, but no real data attaches to these. */
  const person = (roles, { name, bot = false } = {}) => {
    const i = n++
    const id = String(900000000000000000n + BigInt(i))
    const label = name ?? `${FIRST[i % FIRST.length]} ${LAST[Math.floor(i / FIRST.length) % LAST.length]}`
    members.push({ nick: label, roles: [...roles], user: { id, username: `fx${i}`, global_name: null, ...(bot ? { bot: true } : {}) } })
  }
  const add = (roles, opts) => person([L.LEGION_ROLE, ...roles], opts)

  // High Command, with a Pyre Guard standing in as 2nd Company's acting head.
  add([L.HIGH_COMMAND[0].id])
  add([L.HIGH_COMMAND[2].id, co(2), cmd(2)])
  add([L.HIGH_COMMAND[2].id])
  add([L.HIGH_COMMAND[3].id])
  add([L.HIGH_COMMAND[4].id])

  // Companies. 2nd is run by the acting head; 6th has nobody, so it is vacant.
  for (const c of L.COMPANIES) {
    const k = c.number
    if (k !== 2 && k !== 6) add([L.CAPTAIN.id, c.roleId, c.commandRoleIds[0]])
    for (let i = 0; i < 2; i++) add([cr('lieutenant').id, c.roleId])
    add([(k % 2 ? cr('company-ancient') : cr('company-champion')).id, c.roleId])
    add([cr('veteran-sergeant').id, c.roleId])
    for (let i = 0; i < 3; i++) add([cr('sergeant').id, c.roleId])
    add([cr('terminator').id, c.roleId])
    for (let i = 0; i < 3; i++) add([cr('company-veteran').id, c.roleId])
    for (let i = 0; i < 6; i++) add([cr('battle-brother').id, c.roleId])
    for (let i = 0; i < (k === 7 ? 24 : 3); i++) add([cr('scout').id, c.roleId])
  }
  add([cr('sergeant').variants[0].id, co(1)]) // a Firedrake Sergeant
  add([cr('sergeant').variants[1].id, co(7)]) // a Scout Sergeant
  add([cr('company-veteran').variants[0].id]) // a Firedrake Veteran with no company role: implies 1st
  add([cr('battle-brother').id, co(3), co(5)]) // two companies: 3rd decides, 5th is "also"
  add([cr('battle-brother').id, co(3)], { name: 'Marcian Flint 5th Co.' }) // name claims a different company

  // Dreadnoughts: Venerable ones are their own branch; the rest sit aside in their company.
  add([L.VENERABLE_DREADNOUGHT.id, co(5)])
  add([L.VENERABLE_DREADNOUGHT.id, co(1)])
  add([L.DREADNOUGHTS[0].id, co(4)])
  add([L.DREADNOUGHTS[1].id, co(1)])

  // Specialties, some with company tags.
  for (const s of L.SPECIALTIES) {
    for (let i = 0; i < (s.key === 'forge' ? 2 : 1); i++) add([s.head.id, ...(i === 0 ? [] : [co(1)])])
    s.ranks.forEach((r, ri) => {
      for (let i = 0; i < 2; i++) add([r.id, ...(i === 0 ? [co(((ri + i) % 7) + 1)] : [])])
    })
  }
  add([spec('reclusiam').ranks[0].variants[0].id]) // a Firedrake Chaplain with no company role

  // Legion members with no company or specialty role, and one with no rank at all.
  for (let i = 0; i < 4; i++) add([cr('battle-brother').id])
  add([])

  // Servitors: a bot, a Servo-Skulls holder, and a viewing account known by name.
  add([co(1)], { name: 'Smith-Servitor', bot: true })
  add([L.SERVO_SKULLS_ROLE], { name: 'Eye Servo Skull' })
  add([], { name: 'Rune Viewing Servitor' })

  // Never listed: the shared admin account, and someone without the Legion role.
  add([L.VOICE_OF_VULKAN_ROLE], { name: 'Voice of Vulkan' })
  person([cr('battle-brother').id], { name: 'Fixture Outsider' })

  // The Infirmary: still carrying the Legion role, rank-stripped, and never Legion.
  add([L.INFIRMARY_ROLE, cr('battle-brother').id, co(3)])
  add([L.INFIRMARY_ROLE, spec('forge').ranks[1].id, co(2)])
  add([L.INFIRMARY_ROLE, cr('scout').id, co(7)])
  add([L.INFIRMARY_ROLE])
  person([L.INFIRMARY_ROLE, cr('battle-brother').id, co(4)])
  person([L.INFIRMARY_ROLE])

  return members
}

export function buildFixture() {
  const guild = syntheticGuild()
  const roster = { fetchedAt: FETCHED_AT, stale: false, viewer: { infirmary: true }, ...buildRoster(guild, { guildId: GUILD }) }
  const members = buildInfirmary(guild, { guildId: GUILD })
  return { _fixture: true, roster, infirmary: { fetchedAt: FETCHED_AT, stale: false, count: members.length, members } }
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  await writeFile(OUT, JSON.stringify(buildFixture(), null, 2) + '\n')
  console.log(`Wrote ${OUT.pathname}`)
}
```

````markdown
## The data contract

`GET /roster` returns `{ fetchedAt, stale, viewer: { infirmary }, highCommand,
branches, unassigned, servitors }`.

- `highCommand`: `[{ rank, members }]`, rank order, empty ranks omitted.
- `branches`: always 12, in order: companies 1–7, `venerable-dreadnoughts`,
  `forge`, `librarius`, `apothecarion`, `reclusiam`. Each has `head` (`rank`,
  `members`, `vacant`), `aside` (Dreadnoughts: honoured, no formal post, drawn
  between the head and the Lieutenants, off to the side) and `rows`
  (`[{ rank, members }]`, top to bottom, empty rows omitted).
- `rank = { key, label, tier, lateral? }`. **Ranks sharing a `tier` are peers**:
  set them side by side, best effort (Company Ancient and Company Champion).
  `lateral` (Terminator) is a specialization of the rank and file, not a step
  toward Sergeant: draw it beside the ladder if you like.
- Head rows across the page are peers too: Captains and Venerable
  Dreadnoughts share tier 1.
- `Member = { id, name, avatar|null, company|null, alsoCompanies?, acting?,
  nameMismatch?, bot? }`. `avatar` is a CDN URL or null (render initials).
  `company` comes from roles only. `acting` marks an acting head (a company
  with no Captain; the person also stays where they already are).
  `nameMismatch` means the display name claims a different company than the
  roles: show a subtle marker so leadership can fix whichever is stale.
  `alsoCompanies` lists extra company roles after the one that placed them.
- `servitors`: the viewing accounts and bots, shown as a deliberate joke at the
  foot of the page.
- `GET /roster/infirmary` returns `{ fetchedAt, stale, count, members }`; each
  member has `rank` (or null if rank roles were stripped), `legion` (they still

  fields. It lists every holder of the Infirmary role, Legion role or not.

server disappear without a refresh. `stale: true` means the server could not
refresh for over ten minutes; say so.
````
