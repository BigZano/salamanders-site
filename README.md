# Salamanders

The clan site for the Salamanders (the XVIIIth Legion), a Warhammer 40,000: Space Marine 2 community, live at
[sm2salamanders.site](https://sm2salamanders.site). Members use it to plan perk builds, browse the armoury, share
builds, and read the order of battle and the Legion Archive. It is mostly used on phones.

It is a Vue 3 and Vite site, with a small API (Bun and Postgres) in `server/`.

## Run it

You need [Git](https://git-scm.com/), [Bun](https://bun.sh/) and [Node.js](https://nodejs.org/) 24.

```
bun install
bun run dev
```

The site is then at http://localhost:5173. `bun run test` runs the tests and `bun run build` makes a production build.
